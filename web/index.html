Free setup, step by step

1

Publish the website

Upload the ZIP’s contents to a public GitHub repository. In Settings → Pages, choose GitHub Actions. The included workflow publishes only the web/ folder.

2

Start your laptop relay

Install Node.js 22+ and FFmpeg. In the project folder run npm ci, then npm run setup. Add your Pages origin and platform keys to relay/.env. Run npm start.

3

Connect your devices

For eligible free personal use, install Tailscale on your laptop and phone, sign in to the same private network, then run tailscale serve --bg http://127.0.0.1:8787 on the laptop. Use its HTTPS address as your relay.

4

Frame, connect, stream

Open this website on your phone. Connect the relay, enter Match ID 986, open the camera in landscape and select destinations. Test privately before match day. Keep the phone unlocked and Tailscale connected.

See README.md and docs/SETUP.md in the ZIP for Windows instructions, platform setup and the limits of free hosting. CricClubs feed access and platform eligibility depend on your account.
