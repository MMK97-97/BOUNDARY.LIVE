READY WHEN YOU ARE

GitHub + your laptop

  1. Upload extracted project files to a public GitHub repository. In Settings → Pages choose GitHub Actions.
  2. Install Node.js 22+, FFmpeg and Tailscale on the laptop. Run npm ci, npm run setup. Edit relay/.env, then npm start.
  3. Connect phone and laptop to your private Tailscale network. Run tailscale serve --bg http://127.0.0.1:8787.
  4. Enter its HTTPS origin and relay token here. Load match 986, open the camera, choose destinations and start.

Read docs/SETUP.md in the ZIP for full instructions, plan eligibility, network capacity and platform requirements.
