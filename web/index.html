READY WHEN YOU ARE

GitHub + your laptop

  1. Push the project to a public GitHub repository. In Settings → Pages choose GitHub Actions. The “Publish mobile studio” workflow deploys the web folder.
  2. Optional: in Actions run “Archive CricClubs match” with your Match ID (or set the BOUNDARY_MATCH_ID repository variable) so the full ball-by-ball history is kept on the data branch.
  3. Install Node.js 22+, FFmpeg and Tailscale on the laptop. Run npm ci, npm run setup. Edit relay/.env, then npm start.
  4. Run tailscale serve --bg http://127.0.0.1:8787, enter its HTTPS origin and relay token here, open the camera, choose destinations and start.

See docs/SETUP.md for full instructions.
