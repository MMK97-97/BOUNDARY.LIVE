Connect your relay first.

READY WHEN YOU ARE

Host once. Stream from your phone.

  1. Upload the extracted source to your GitHub repository, including Dockerfile and render.yaml.
  2. In your cloud host’s mobile dashboard, deploy the repository as a Docker web service. The container includes Node.js, FFmpeg and fonts.
  3. Set a private RELAY_TOKEN and the service’s PUBLIC_URL (Render supplies its own URL automatically). Open that HTTPS address on your phone.
  4. Unlock your cloud studio here. Connect YouTube or paste current platform keys, load your match and open the camera.
  5. Press START, then use the platform’s preview and publishing controls. YouTube live controls are inside MK97.

A running cloud service is required; GitHub Pages and Actions cannot encode an ongoing broadcast. Free hosting may have resource, bandwidth or uptime limits. Read docs/CLOUD_SETUP.md in the ZIP before choosing a plan.

One-time Google setup

Enable YouTube Data API v3 in your Google Cloud project. Create a Web application OAuth client, add this website’s exact youtube-callback.html URL, and set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET and YOUTUBE_REDIRECT_URI in your cloud service’s secret environment settings. Redeploy the service. Full instructions: docs/YOUTUBE.md in the ZIP.
